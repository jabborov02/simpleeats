# SimpleEats

SimpleEats is a basic online food ordering system built with PHP, MySQL, HTML, CSS, and JavaScript. The project allows customers to browse restaurants, view menu items, place orders, and view order history. It also includes an admin panel for managing restaurants, menus, and orders.

## Features

- Customer-facing restaurant and menu browsing
- Order placement and order history pages
- Admin login system
- Admin dashboard for managing restaurants, menu items, and orders
- CRUD functionality for core food ordering data
- Form validation and database-backed functionality

## Tech Stack

- PHP
- MySQL
- HTML
- CSS
- JavaScript
